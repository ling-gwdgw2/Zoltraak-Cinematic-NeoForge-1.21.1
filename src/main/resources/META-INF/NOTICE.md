## 2. Clean-Room Implementation & Originality Statement

As of **Version 1.0.4** and all subsequent releases:
- All Java source code, procedural vector mesh algorithms (Blaze3D / JOML), GLSL 150 core shaders, and JSON configurations are 100% original, clean-room creations developed independently.
- The mod runs on dedicated custom shaders and procedural textures without external shaderpack dependencies.

---

## 3. Historical Prototype Clarification (v1.0.0 – v1.0.2fix)

During early experimental prototyping prior to version 1.0.4, initial shader prototypes tested concepts from *Frieren Spells* by sho09 (MIT License). In Version 1.0.4, all legacy prototypes, borrowed shaders, and atlas textures were permanently deleted and replaced with original procedural implementations.
